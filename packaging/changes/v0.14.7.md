### v0.14.7の変更 / Changes

- PPMS Resistivityのフィット曲線・残差、Heat Capacityの低温フィットは実行済み温度範囲内で表示。
- Custom PlotのDatasets右クリックから手動ブランチを設定。各ブランチの表示・スタイル・フィット設定を保持。
- Search–Matchのダーク配色と、Send to Igor／Graph Editorアイコンの線幅を修正。
- 機能配置を維持し、ライト／ダークの見出し、入力欄、フォーカス、選択・無効状態を統一。

PPMS fit curves and residuals now stay inside their saved temperature bounds.
Custom Plot supports manual branches from the dataset context menu. Search–Match
respects dark mode, the two toolbar icons use lighter consistent strokes, and
shared desktop styling improves hierarchy/focus without moving existing features.


#### パネル・操作ボタンの改善 / Panel and button refinements

- 中央グラフを優先するカラム配分、幅・表示状態の記憶、グラフ集中表示と復元を追加。
- 編集対象と設定タブを固定し、カテゴリ内だけをスクロール。適用範囲表示と安全な折りたたみを統一。
- 配色操作を展開式にまとめ、データ操作・削除を分離。診断の全文表示を追加。
- 長い解析設定にも対象が明確な実行欄・結果表示を固定。残差の表示・高さを保持。
- 相検索、ピークフィット、ブランチ編集、計算列のボタン群を役割別に整理。
- 新規・変更した操作ラベル、ヒント、アクセシビリティ名を日本語・英語で確認。
- Graph Editorのファイル選択後の読み込みで、確定処理中に画面が破棄される問題を修正。

Columns prioritize the plot and retain widths/visibility, with explicit focus and
restore controls. The editing target and category tabs stay fixed while each category
scrolls. Section folding preserves conditional controls. Dataset color tools expand
on demand; selected-data actions and removal are distinct. Context-bound analysis
execution and result access stay reachable. Residual and Graph Editor docks retain
user choices. Search, fitting, branch and column actions use consistent groups and
roles, with Japanese/English captions and narrow-window wrapping.
Graph Editor also keeps file-selection dialogs alive until their completion
handlers return, preventing deletion during a nested file-reading progress loop.

This replaces the earlier v0.14.7 installer. Save work and close MDS before running
the new Setup.exe, including when v0.14.7 is already installed. Reference database ZIPs
are unchanged. / 既公開v0.14.7のインストーラを差し替えています。同じv0.14.7を導入済みの場合も、
作業を保存してMDSを終了してから新しいSetup.exeを実行してください。参照DB ZIPは変更していません。


#### 表示操作をViewへ統合 / Display actions moved to View

メイン画面とGraph Editor上部のパネル表示・集中表示・配置初期化などのボタン列を廃止し、
Helpの左隣のView（表示）メニューへ統合しました。メイン画面では現在のタブに適用され、
残差パネルの表示と高さ復元も同メニューから行えます。Graph EditorのCommand／Procedureは
チェック付きメニューで切り替えられます。既存の幅・表示状態・ドック復元と日英表示を保持しています。

The display-button rows above the main workspace and Graph Editor have been removed.
Their actions are in View, immediately before Help. Main-window actions follow the
active XRD/MPMS/PPMS tab, including residual visibility and height restoration.
Graph Editor keeps Command/Procedure checkboxes and docking actions in the same View
menu. Existing widths, visibility preferences, dock restoration and bilingual labels
are preserved. This is a further replacement of the v0.14.7 installer.
